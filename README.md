# 🔍 Crime Classification in San Francisco 🚔  

## 🚀 Project Overview  
This project analyzes and classifies crimes in **San Francisco**, leveraging machine learning models to predict crime categories. We experimented with multiple models and evaluated their performance **before and after hyperparameter tuning**.  

---

## ⚡ Model Performance  

| 🏆 Model                  | 🎯 Accuracy (Without Tuning) | 🎯 Accuracy (With Tuning) |
|-------------------------|-------------------------|-------------------------|
| 🔹 Logistic Regression     | **0.9719** | **0.9971** |
| 🔸 Naive Bayes            | **0.9938** | **0.9957** |
| 🌲 Random Forest         | **0.6109** | **0.8146** |
| 🌳 Decision Tree         | **0.4729** | **0.8796** |

✅ **Key Takeaways:**  
- **Logistic Regression** performs exceptionally well with tuning.  
- **Naive Bayes** is already quite optimized but improves slightly with tuning.  
- **Random Forest & Decision Tree** benefit **significantly** from hyperparameter tuning.  

---

## 🛠️ Models Used  
- 🔹 **Logistic Regression** - Simple yet effective for classification tasks.  
- 🔹 **Naive Bayes** - Strong for probabilistic classification.  
- 🔹 **Random Forest** - Powerful ensemble model but requires tuning.  
- 🔹 **Decision Tree** - Good for interpretability but overfits without tuning.  

---

## 📊 Dataset  
The dataset includes **real-world crime reports from San Francisco**, categorized into different offenses such as **theft, fraud, assault, vandalism, and more**. The goal is to predict the crime category based on features like **location, time, and crime description**.
